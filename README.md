# Salesforce MuleSoft Integration Framework

Enterprise Salesforce integration framework demonstrating Apex callouts, Queueable Apex, Named Credentials, and MuleSoft API integration patterns.

## Features

- Apex HTTP Callouts
- Named Credential Integration
- Queueable Apex
- Mock API Testing
- Error Handling
- JSON Response Processing

## Tech Stack

- Salesforce Apex
- REST APIs
- MuleSoft
- Queueable Apex
- Named Credentials

## Enterprise Use Case

This project represents a real-world healthcare integration pattern where Salesforce retrieves member information from external systems through MuleSoft APIs.
